Сценарий покупки/продажи.
Продавец:   загружает конспект, указывает цену продажи, указывает номер карты.
Админ:      одобряет конспект.
Продавец:   получает уведомление / видит конспект в разделе "Мои конспекты".
Покупатель: выбирает конспект, получает номер карты админа.
Админ:      получает уведомление / видит заявку на покупку в разделе "Активные заказы".
Покупатель: переводит деньги на карту (цена продажи + комиссия).
Админ:      подтверждает поступление денег, переводит деньги продавцу.
Покупатель: получает уведомление / видит конспект в разделе "Купленные конспекты".
Покупатель: скачивает конспект по ссылке.

Разделы меню:
1. Покупка
  - Выбрать конспект: Курс -> Предмет -> Конспект
  - Купленные конспекты:
    - "Ждёт оплаты" - до перевода денег
    - "В обработке" - после перевода денег, админ проверяет правильность перевода
    - "Доступен к скачиванию" - есть ссылка на скачивание
2. Продажа
  - Продать конспект: Курс -> Предмет -> Цена продажи -> Реквизиты (если нет, создать и сохранить)
  - Мои конспекты:
    - "На проверке" - загружен и ждёт одобрения админом
    - "Одобрен" - одобрен админом и доступен для покупки
  - Мои реквизиты:
    - список сохранённых реквизитов
    - "Добавить"
    - "Удалить"
3. О нас

К конспекту прикрепляется цена продажи и реквизиты продавца.
